# HyperFrames project files (shared)

Per-project compositions are written by the build stage into each project's own
`compositions/` directory (`<project>/compositions/index.html`).

This shared folder holds reusable HyperFrames fragments/templates that the
BUILDER may be pointed at explicitly by a plan. It starts empty on purpose:
templates only land here once a delivered film proves them (§24), so the
catalog never accumulates untested motion.
